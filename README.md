# Student Grade Calculator (C++)

My first C++ project — a console-based Student Grade Calculator developed as part of my journey into Computer Science and programming.

## Features
- Accepts the student's full name
- Accepts marks for 6 subjects
- Validates marks between 0 and 100
- Calculates total score out of 600
- Calculates overall percentage
- Determines Pass/Fail status
- Assigns a final letter grade (A–F)

## Subjects
- Critical Thinking & Problem-Solving
- Physics
- Calculus 1
- Introduction to Computer Science
- Discrete Mathematics
- Professional Ethics

## Passing Requirements
- Minimum overall percentage: 65%
- Minimum mark in every subject: 50%

## Technologies Used
- C++
- `iostream`
- `string`
- Conditional statements
- Logical operators
- Basic arithmetic
